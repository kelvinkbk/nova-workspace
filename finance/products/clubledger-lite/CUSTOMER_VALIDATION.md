# ClubLedger Lite — first-customer validation

Status: internal draft only. Nothing has been sent or published.

## Goal
Find out whether student club treasurers actually want a simple offline income/expense tracker before spending time on a storefront. Upfront spend: ₹0.

## Message to send manually
Hey! I'm testing a tiny offline finance tracker for student clubs/committees. It records income and expenses, shows monthly totals and the overall balance, and exports CSV/JSON backups. It runs locally in a browser; it doesn't sync between people or connect to UPI/banks.

Would this solve any real problem for your committee? What would you need changed before you'd use it? Honest feedback is enough — I'm validating the idea, not asking you to buy anything right now.

## Ask these three questions
1. How do you currently track club/event money — notebook, Excel/Sheets, or another app?
2. What's the most annoying part of that process?
3. Would an offline single-device tool be useful, or do you need shared access for multiple committee members?

## Validation rule
- Talk to 5 relevant people before deciding whether to launch.
- Record only real responses; don't invent testimonials or demand.
- If 0–1 people show interest, improve or change the idea before listing it.
- If 2+ people show a concrete use case, offer a voluntary test copy and ask them to try it with dummy data first.
- Never ask anyone to put sensitive financial records into an untested prototype.
- Do not publish, contact people, create a seller account, or set up payouts automatically. Owner review/approval is required.

## Product caveats to disclose
- Prototype; broad interactive browser testing is still pending.
- Data stays in that browser/device; no multi-user sync.
- Clearing browser storage can erase data, so export backups.
- No bank/UPI integration and no claim of independently verified accounting.
